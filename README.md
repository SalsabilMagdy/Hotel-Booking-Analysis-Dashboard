# 🏨 Hotel Booking & Hospitality Analytics Dashboard

An interactive Excel dashboard built to analyze hotel reservation data, guest trends, and revenue generation in the hospitality industry. This project translates raw booking records into clear visual summaries to support data-driven decision-making.

## 📊 Key Highlights & Insights
* **Revenue Tracking:** Evaluated overall performance, tracking total sales (**$78M**) and overall booking quantities.
* **Geographical Distribution:** Utilized a **Tree Map** to identify top-performing cities with the highest booking volumes.
* **Booking Fulfillment Status:** Monitored order processing rates (Shipped vs. Cancelled bookings) to evaluate operational workflows.
* **Customer Segmentation:** Analyzed guest demographics and segment distributions to identify key target markets.

---

## 🛠️ Tools & Techniques
* **Microsoft Excel:** Data cleaning, structuring, and feature engineering.
* **Pivot Tables & Pivot Charts:** Dynamic aggregation of hospitality data.
* **Interactive Slicers:** Enabled seamless filtering across cities, customer segments, and booking statuses.
